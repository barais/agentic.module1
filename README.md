# MODULE 1 — Grands modèles de langage (le socle)
> Objectif : donner le vocabulaire commun avant l'agentique. À adapter selon ton public (néophyte ou initié).

1. **Qu'est-ce qu'un LLM ?** — définition, exemple, qu'est-ce qu'il sait faire (générer, résumer, traduire, coder…)
2. **Comment ça marche ?** — tokenisation, transformer, attention (concept simple), pré-entraînement vs post-entraînement
3. **Capacités émergentes** — raisonnement, in-context learning, suivre des instructions
4. **Reconnaissance et limites** — hallucination, fenêtre de contexte, biais, coûts
5. **Prompting et raisonnement** — prompt engineering, chain-of-thought, « reasoning models » (test-time compute)
6. **RAG (Retrieval-Augmented Generation)** — donner accès à des connaissances externes ; distinction RAG vs agent
7. **Fine-tuning vs prompting** — quand adapter un modèle plutôt que de l'utiliser tel quel
